BDON Immersive Home (네이티브 Windows 버전)
=========================================

실행 방법
---------
1. 압축을 푼 폴더 전체를 원하는 위치에 둡니다
   (BDONImmersiveHome.exe 와 data 폴더가 같은 폴더에 있어야 합니다).
2. BDONImmersiveHome.exe 를 실행합니다.
3. 바탕화면 아이콘 뒤에 배경이 나타나고, 작업 표시줄 트레이에 아이콘이 생깁니다.
4. 트레이 아이콘을 왼쪽 클릭하거나 오른쪽 클릭 → "배경 설정…" 으로
   설정 창을 엽니다.

트레이 메뉴
-----------
- 배경 설정…      : 설정 창 열기
- 캐릭터 표시     : 캐릭터 표시/숨김
- 장면 셔플       : 일정 시간마다 배경 자동 전환
- 종료            : 프로그램 종료

설정 창
-------
- 밴드별로 배경 썸네일이 정렬됩니다. 클릭하면 그 배경으로 바뀝니다.
- "장면 셔플" 을 켜면, 썸네일 클릭이 셔플 대상(풀) 포함/제외 토글로 바뀝니다
  (풀에서 빠진 배경은 어둡게 표시).
- 아래 고정 바에서 캐릭터 표시 / 커서 따라 시점 이동 / 장면 셔플 을 켜고,
  변경 주기(1·5·10·30분·1시간)를 고를 수 있습니다.

파일 위치
---------
- 설정 파일 : %APPDATA%\BDONImmersiveHome\settings.json
- 로그 파일 : %LOCALAPPDATA%\BDONImmersiveHome\log.txt

SmartScreen 안내
----------------
서명되지 않은 실행 파일이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수
있습니다. "추가 정보" → "실행" 을 누르면 실행됩니다.

문제 해결
---------
- 배경이 보이지 않으면 로그 파일에서 HARDWARE / WARP, 오류 메시지를 확인하세요.
- GPU 가 없는 환경(가상 머신 등)에서는 자동으로 WARP(소프트웨어 렌더링)로
  동작합니다.
