BDON Immersive Home (Windows)
=============================

설치
----
1. 압축을 풉니다 (BDONImmersiveHome.exe 와 data 폴더가 같은 폴더에 있어야 합니다).
2. BDONImmersiveHome.exe 를 실행하고 "설치할까요?" 에서 [예] 를 누릅니다.
   - %LOCALAPPDATA%\Programs\BDON Immersive Home 에 설치됩니다 (관리자 권한 불필요).
   - 시작 메뉴에 추가되고, Windows 를 시작할 때 자동으로 실행됩니다.
   - [아니요] 는 설치하지 않고 이 폴더에서 바로 실행합니다.
   - 새 버전을 받으면 같은 방법으로 실행해 업데이트합니다.
3. 설치가 끝나면 압축을 푼 폴더는 지워도 됩니다.

제거: 설정 > 앱 > 설치된 앱 > BDON Immersive Home > 제거

트레이 메뉴
-----------
- 배경 설정…                  : 설정 창 열기
- 캐릭터 표시                 : 캐릭터 표시/숨김
- 장면 셔플                   : 일정 시간마다 배경 자동 전환
- Windows 시작 시 자동 실행   : 자동 실행 켜기/끄기
- 종료

Windows 11 은 새 트레이 아이콘을 작업 표시줄의 ^ (숨겨진 아이콘) 안에 넣습니다.
항상 보이게 하려면 설정 > 개인 설정 > 작업 표시줄 > 기타 시스템 트레이
아이콘 에서 BDON Immersive Home 을 켭니다.

파일 위치
---------
- 설정 파일 : %APPDATA%\BDONImmersiveHome\settings.json
- 로그 파일 : %LOCALAPPDATA%\BDONImmersiveHome\log.txt

SmartScreen 안내
----------------
서명되지 않은 실행 파일이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수
있습니다. "추가 정보" → "실행" 을 누르면 실행됩니다.
